# Smart Organizer: AI-Based Task & Shopping Management System

## 📌 Overview
Smart Organizer is an AI-based application designed to manage daily tasks and shopping activities efficiently. It integrates task scheduling, shopping reminders, email classification, and basic AI features like chatbot and voice assistance to enhance user productivity.

## 🎯 Objective
To develop an intelligent system that helps users organize tasks, manage shopping lists, and receive timely reminders using automation and data-driven features.

## 🛠️ Technologies Used
- Python
- Machine Learning
- Pandas
- (Add Streamlit / Flask if you used)
- Email Classification Techniques

## 🚀 Key Features

### 🛒 Shopping Management
- Add shopping items with deadlines
- Get reminders (e.g., "2 days to go")

### ✅ Task Management
- Create and manage tasks with due dates
- Automated reminder notifications

### 🤖 AI Features
- Chatbot for basic interaction
- Voice assistant (partially functional)

### 📧 Email Classification
- Classifies emails based on content
- Helps in organizing communication efficiently

### 📊 Data Handling
- Uses structured data and pivot-based insights

### 🌐 User Interface
- Navigation bar for easy access
- Contact Us section
- Feedback submission feature

## 📊 How It Works
- User inputs tasks or shopping items
- System tracks deadlines
- Generates reminders automatically
- AI components assist with interaction and classification

## 📈 Outcome
The project improves productivity by combining task management, shopping reminders, and AI-based features into a single platform.

## ⚠️ Limitations
- Voice assistant is not fully functional
- Supports only a single user
- Limited scalability

## 🔮 Future Improvements
- Multi-user support
- Fully functional voice assistant
- Mobile application integration
- Enhanced AI capabilities
